## About

A responsive promotional website created for **Laguna HAWKS**, a student team designing and building a gravity race car. The page presents the project, engineering concept, development timeline and sponsorship invitation through a cinematic visual experience.

## Highlights

- Original racing-inspired visual identity
- Animated hero, counters and entrance sequences
- Custom cursor and motion interactions
- Vehicle technology and safety sections
- Hawk-01 development timeline
- Team and sponsorship storytelling
- Responsive layouts and direct contact actions

## Technology

Semantic HTML5 · CSS custom properties · Vanilla JavaScript · Scroll animations · GitHub Pages

## Run locally

```bash
git clone https://github.com/abrilvillita/Laguna-Hawks-Landing-Page.git
cd Laguna-Hawks-Landing-Page
```

Open `index.html` in a modern browser.

## Project context

This was developed for a real student organization rather than as a tutorial clone. The goal was to communicate the team's ambition and support sponsorship outreach.
